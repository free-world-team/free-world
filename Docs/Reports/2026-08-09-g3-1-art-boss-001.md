## 3. 关键架构决定

- 使用 `imagegen` 技能内置模式，折枝/听风各一次纯文字原创调用；不使用图片输入、参考项目资源、
  品牌或外部素材。服务未暴露模型版本和 Seed，按不可取得如实记录。
- 每张 Atlas 固定行序 Down/Left/Right/Up，列序 Move/Hit/Phase1Windup/Transition2/Phase2Windup/
  Transition3/Phase3Windup/Defeated；ART-BOSS-002 保留六张独立阶段/Telegraph Overlay，不在本批混入。
- ImageGen 原生输出为 1672×941（折枝）与 1774×887（听风）；经透明化后先产出 4096×2048 可审计
  master，再产出 2048×1024 runtime final，满足单纹理长边≤2048 与 256 方格预算。
- 初次 `component-layout` 假设等距格中心，因生成图实际横向间距不均而漏掉 `(row 1, column 4)`，
  命令 `FAIL` 且未写 normalized/final。新增通用 `component-sequence-layout`：从 Alpha 投影谷切四行，
  每行保留八个最大连通主体并按 X 排序；同时确定性移除小碎屑，无手工重绘。
- 折枝以浅木枝架/叶冠/叉头练习剑，听风以深色铁木/石甲/铜风标/青色誓缚形成独立轮廓；败北姿势
  均为卸下职责的完整跪姿而非彻底破坏，符合叙事约束。
- Profile 绑定现有 `qinglan.enemy.boss.*` 与 `down.move`。阶段动画状态驱动和 Player 正式装载留在
  G3.1 最终集成，不把 Addressables 注册表述为运行时已经消费。
