## 3. 关键决定

- 24 个 Glyph 覆盖 M7 Runtime 的 Gameplay/UI 主绑定：Move、Pause、Map、Interact、Navigate、Submit、
  Cancel、Tab 和 Page。Development-only F2/F3 不进入 Release；Space 作为 Submit 次要备选不单独占用
  Glyph，正式提示优先使用 Enter/面键 South。
- W/A/S/D/E/M/Q 由第一方线段路径绘制，不加载字体。手柄面键以 South/East/North 方位表达，不使用
  A/B/X/Y、Xbox、PlayStation 或其他平台品牌语言。
- Glyph 只表达物理控件；活动设备判断、重绑定路径、命令语义和可用状态仍由 Input/UI Owner 决定。
- 每张 final 为独立 128 Sprite，中心 Pivot、零 Border、无 MipMap、Standalone BC7；24 张全量常驻的
  BC7 基础占用约 384 KiB，远低于 UI 64 MiB 推荐预算，仍由最终集成决定按页面加载/释放。
- 未改变 Content Schema、存档、程序集依赖、Tick 或运行时加载架构，无需新增 ADR。
