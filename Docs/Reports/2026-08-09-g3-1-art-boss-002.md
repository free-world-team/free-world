## 3. 关键架构决定

- 使用仓库自有脚本确定性生成，不调用 ImageGen，不使用外部素材、图片参考、第三方品牌或参考项目资产。
- 六个契约以几何语义而非仅靠颜色区分：折枝依次为横向长廊、三目标环、八角阵；听风依次为斜向
  冲锋走廊、破碎螺旋、交叉誓约通道。
- P0 危险色固定为 `#E45D45`，警示高光固定为 `#FFD0A3`，并配合深色描边；用户可见正文不烘焙进图片。
- 每张源图为 2048×2048，final 为 1024×1024 RGBA；Alpha≥16 覆盖率 12.38%—22.81%，安全边≥60 px，
  兼顾战斗可读性与叠加填充率。
- 只有 `final/` 六张文件进入 `QinglanDemo-Visual`；Prompt、规格、source 和 provenance 均不可寻址。
- 本批只建立正式资产契约。阶段状态映射、显示生命周期和材质叠加在 G3.1 最终集成统一接入，避免把
  Addressables 注册误报为 Player 已消费。

## 4. 实际执行的命令

```text
python Scripts/generate-qinglan-boss-telegraph-overlays.py（首次生成）
python Scripts/generate-qinglan-boss-telegraph-overlays.py（第二次生成并比较 12 个 SHA-256）
Unity -executeMethod Game.Editor.QinglanVisualAssetImportCommand.Run（六张 final 各一次）
.\Scripts\test.ps1 -Platform EditMode -ResultsDirectory TestResults/G31ArtBoss002
.\Scripts\test.ps1 -Platform PlayMode -ResultsDirectory TestResults/G31ArtBoss002
.\Scripts\validate.ps1 -LogPath TestResults/G31ArtBoss002/validation.log
```

第一次 EditMode 外层命令的 1 秒等待上限先结束，但 Unity 子进程继续正常执行；读取实际进程、日志和
XML 后确认它以退出码 0 完成。未并发重复启动测试，随后所有结果均取自该完整测试运行。
