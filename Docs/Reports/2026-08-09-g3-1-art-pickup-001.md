## 3. 关键架构决定

- 依据 Manifest 的 `original_ai_assisted_no_reference_input`，使用 imagegen 技能的 built-in 模式，每种
  灵物一次独立文字调用；没有上传参考图、项目图或第三方图。
- 统一使用纯洋红键色背景；按技能规定用 bundled `remove_chroma_key.py` 执行 border auto-key、soft
  matte、despill 和 12/220 阈值，不切换 CLI 或原生透明模型。
- 六种轮廓分别锁定为叶芽露瓶、四角定界牌、六尖雷玉、双腹葫芦、圆角护心牌和阶梯玉羽，避免只靠颜色。
- 每份透明 working 只作确定性裁切/缩放，不进行手绘修补；Sprite 与 Icon 共享同一批准主体。
- 只有 `final/` 12 个纹理可寻址；source、working、Prompt 和 provenance 不可寻址，不创建 VisualProfile。

## 4. 实际执行的命令

```text
Codex built-in ImageGen（六种灵物各一次、无图片输入）
Copy-Item（六份默认生成目录文件复制到仓库 source；保留原件）
python remove_chroma_key.py --auto-key border --soft-matte --transparent-threshold 12 --opaque-threshold 220 --despill（六次）
python Scripts/process-qinglan-pickup-visuals.py
python remove_chroma_key.py（首次确定性复测未带 --force，安全拒绝覆盖）
python remove_chroma_key.py --force（六次）＋ pickup processor（第二次批准轮）
Unity -executeMethod Game.Editor.QinglanVisualAssetImportCommand.Run（12 个 final 各一次）
.\Scripts\test.ps1 -Platform EditMode -ResultsDirectory TestResults/G31ArtPickup001
.\Scripts\test.ps1 -Platform PlayMode -ResultsDirectory TestResults/G31ArtPickup001
.\Scripts\validate.ps1 -LogPath TestResults/G31ArtPickup001/validation.log
```

首次确定性复测因去背工具默认禁止覆盖而退出，没有修改文件；补充 `--force` 后，6 working＋12 final
共 18/18 SHA-256 字节一致。
