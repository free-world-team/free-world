## 3. 关键架构决定

- 六套资产使用仓库自有 Python/Pillow 几何脚本，不调用 ImageGen，不使用外部素材、图片参考、字体、
  第三方品牌、宗教文字或参考项目资源。
- 技能辨识依赖轮廓/轨迹/内部标记而非只靠颜色：回返横剑、切角竖符、六段环轮、双向潮弧、八角山印、
  三向藤蔓分别映射六种基础闭环。
- 正式 Sprite 使用中心 Pivot；游风剑/黄符/飞轮 Profile 为 `EntityKind.Projectile`，听潮珠/震岳印/
  灵藤种为 `EntityKind.Area`，并保存各自缩放。枚举底层值修复已在前置独立提交 `64cadd9` 关闭。
- 用户友方核心不使用精确 P0 危险色 `#E45D45`；统一深青描边，暖色飞轮也以象牙白/青色部件维持阵营。
- 只有六张 `final/` 与六个 Profile 可寻址；source、Prompt、规格和 provenance 不可寻址。
- Profile StableId 使用 `qinglan.presentation.skill.*`。当前技能定义仍使用 `placeholder.presentation.*`，
  在 G3.1 最终集成一次性替换并验证，不把资产注册误报为运行时已消费。

## 4. 实际执行的命令

```text
python Scripts/generate-qinglan-base-weapon-visuals.py（首轮；黄符覆盖率 33.32%，视觉预算 FAIL）
python Scripts/generate-qinglan-base-weapon-visuals.py（缩窄黄符后的批准轮）
python Scripts/generate-qinglan-base-weapon-visuals.py（第二次批准轮并比较 12 个 SHA-256）
Unity -executeMethod Game.Editor.QinglanVisualAssetImportCommand.Run（六张 final 各一次）
Unity -executeMethod Game.Editor.QinglanVisualProfileCreateCommand.Run（修复前六次，仅暴露类型偏移，未注册）
Unity -executeMethod Game.Editor.QinglanVisualProfileCreateCommand.Run（提交 64cadd9 后六次，正确类型）
Unity -executeMethod Game.Editor.QinglanVisualProfileRegisterCommand.Run（六次）
.\Scripts\test.ps1 -Platform EditMode -ResultsDirectory TestResults/G31ArtSkill001
.\Scripts\test.ps1 -Platform PlayMode -ResultsDirectory TestResults/G31ArtSkill001
.\Scripts\validate.ps1 -LogPath TestResults/G31ArtSkill001/validation.log
```

首轮黄符覆盖率超过规格上限，判定 `FAIL`；缩窄切角竖符后由 33.32% 降至 27.89%。首次 Profile 创建
命令本身退出码为 0，但人工读取 YAML 发现既有 `enumValueIndex` 偏移，未注册这些 Profile；缺陷经
`64cadd9` 独立修复并完整回归后，本批重新创建、核验底层值，再执行正式注册。
