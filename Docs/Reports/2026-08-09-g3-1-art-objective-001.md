## 3. 关键架构决定

- 依据 Manifest 的 `original_ai_assisted_no_reference_input`，使用 imagegen 技能 built-in 模式；每座风脉台
  一次独立文字调用，听风台因源级失败额外重试一次；没有上传参考图、项目图或第三方图。
- 听风台初版底座出现未请求的拟人面具式石雕，人工 QA 判定 `FAIL`；失败源保留审计但不参与去背、
  派生或 Addressables。批准重试严格限定为圆环、夹具、直槽等纯几何结构。
- 三态不依赖单纯换色：听风翼展开、引风叶转向、止衡板/配重归位分别提供结构进展；Active/Complete
  青色能量像素必须高于 Idle。
- 按技能规定使用 border auto-key、soft matte、despill 和 12/220 阈值去背；每个 final 使用 3×1、
  320 方格，总宽 960，低于 1024 运行时上限。
- 只有 `final/` 三张 Atlas 可寻址；批准/失败 source、working、Prompt 和 provenance 全部不可寻址。

## 4. 实际执行的命令

```text
Codex built-in ImageGen（听风台首版＋重试、引风台、止衡台；均无图片输入）
Copy-Item（三份批准 source＋一份失败候选复制到仓库；保留默认生成目录原件）
python remove_chroma_key.py --auto-key border --soft-matte --transparent-threshold 12 --opaque-threshold 220 --despill（三次）
python Scripts/process-qinglan-wind-altars.py
去背＋wind-altar processor 完整链第二轮
Unity -executeMethod Game.Editor.QinglanVisualAssetImportCommand.Run（三个 final 各一次）
.\Scripts\test.ps1 -Platform EditMode -ResultsDirectory TestResults/G31ArtObjective001
.\Scripts\test.ps1 -Platform PlayMode -ResultsDirectory TestResults/G31ArtObjective001
.\Scripts\validate.ps1 -LogPath TestResults/G31ArtObjective001/validation.log
```

第二次完整后处理后 3 透明 working＋3 source master＋3 state master＋3 final 共 12/12 SHA-256 字节一致。
