## 3. 关键架构决定

- 依据 Manifest 的 `original_ai_assisted_no_reference_input`，使用 imagegen 技能 built-in 模式，每种奇物
  一次独立文字调用；没有上传参考图、项目图或第三方图。
- 使用纯洋红键色，按技能规定执行 border auto-key、soft matte、despill 和 12/220 阈值；没有切换 CLI。
- 六种轮廓锁定为刃穗、三叶风轮、三瓣种舱、三孔木核、缺口古钟和剑槽牌，避免只靠色彩识别。
- 无字试剑牌保持空白，只保留剑形凹槽；所有奇物禁止可读文字/宗教符号，且不使用 P0 危险红。
- 只有 `final/` 六个纹理可寻址；source、working、Prompt 和 provenance 不可寻址，不创建 VisualProfile。

```text

python remove_chroma_key.py --auto-key border --soft-matte --transparent-threshold 12 --opaque-threshold 220 --despill（六次）
python Scripts/process-qinglan-relic-icons.py
python remove_chroma_key.py --force（六次）＋ relic processor（第二次批准轮）
Unity -executeMethod Game.Editor.QinglanVisualAssetImportCommand.Run（六个 final 各一次）
.\Scripts\test.ps1 -Platform EditMode -ResultsDirectory TestResults/G31ArtRelic001
.\Scripts\test.ps1 -Platform PlayMode -ResultsDirectory TestResults/G31ArtRelic001
.\Scripts\validate.ps1 -LogPath TestResults/G31ArtRelic001/validation.log
```
