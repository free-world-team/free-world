## 3. 关键架构决定

- 两张磁盘交付文件保持 Manifest 要求的 2560×1440；Unity Standalone 上限设为 2048，Runtime Sprite 为
  2048×1152，符合单张 Runtime Texture 通常不超过 2048 的预算。
- Unity 6 对超过 Runtime 上限的 1×1 Multiple Sprite 会再次缩放 Sprite Rect；通用导入器仅对此类单图
  改用 Single Sprite。多格 Atlas 仍使用原有 Multiple 流程，且超预算多格源会明确失败。
- 标题主视觉安全区固定为归一化 `(0.04,0.05)—(0.55,0.64)`；Logo 安全背景为
  `(0.20,0.06)—(0.80,0.62)`。两区均以亮度均值≥215、标准差≤20、边缘率≤0.03 自动验证。
- 未改变 Content Schema、存档、程序集依赖或运行时加载架构，无需新增 ADR。
