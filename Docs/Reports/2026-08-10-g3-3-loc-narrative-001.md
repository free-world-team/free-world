- 保留 Bake Catalog 已使用的 `story.*` 与 `collectible.*.body` Key；新增演出文案统一使用
  `narrative.qinglan.<domain>.<id>.<state-or-index>`。
- 目标/事件固定四状态，连续对白固定两位顺序号，使 UI 和演出层只消费稳定 Key。

  古誓构成的灵结。最终表未保留身份混淆文案。
- 正式叙事与 `M8LegacyUI` 分离，旧占位正文不进入 Release 资产。
- 未改变 Schema、存档或程序集依赖，不新增 ADR。
