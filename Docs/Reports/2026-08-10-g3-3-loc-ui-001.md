## 3. 关键架构决定

- 不删除旧表内容：原 `UI` 安全改名为 `M8LegacyUI`，再创建干净的正式 `UI`。这使历史测试数据
  可追溯，同时 Release 表不会携带 development-only 内容。
- 正式 `UI` 只放 UI、存档和平台诊断；内容名称/描述与叙事分别进入后续两个 Collection。
- Pseudo 由正式英文自动生成，不作为独立翻译源，避免三套文案漂移。
- Localization 自动分组中的正式三项被移动到 `QinglanDemo-Localization`，地址 `UI_en`、
  `UI_zh-Hans` 及 Shared Data 保持 Unity Localization 可解析。
- 未产生需要 ADR 的长期架构变化；这是已规划的 G3.3 内容分包落实。
