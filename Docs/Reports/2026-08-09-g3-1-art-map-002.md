## 3. 关键架构决定

- 依据 Manifest 的 `original_ai_assisted_no_reference_input`，使用 imagegen 技能 built-in 模式，每个区域
  Prop Set 一次独立文字调用；没有上传参考图、项目图或第三方图。
- 每张 source 固定 4×4、16 个隔离物件；按技能规定使用 border auto-key、soft matte、despill 和
  12/220 阈值去背，再按 Alpha≥16 独立裁切和居中，避免把洋红键色或相邻道具带入 Sprite。
- 五套只表达非交互环境陈设；明确排除三座风脉台、三事件、五地标等后续批次独占视觉，避免语义冲突。
- 每个 final 使用 8×2、256 方格以保持 2048 运行时纹理上限；每格至少 24 px 透明安全边。
- 只有 `final/` 五张 Atlas 可寻址；source、透明 working、master、Prompt 和 provenance 不可寻址，
  不创建 VisualProfile、Prefab 或第三方运行时依赖。

## 4. 实际执行的命令

```text
Codex built-in ImageGen（五个区域各一次、无图片输入）
Copy-Item（五份默认生成目录文件复制到仓库 source；保留原件）
python remove_chroma_key.py --auto-key border --soft-matte --transparent-threshold 12 --opaque-threshold 220 --despill（五次）
python Scripts/process-qinglan-region-prop-sets.py
去背＋prop processor 完整链第二轮
Unity -executeMethod Game.Editor.QinglanVisualAssetImportCommand.Run（五个 final 各一次）
.\Scripts\test.ps1 -Platform EditMode -ResultsDirectory TestResults/G31ArtMap002
.\Scripts\test.ps1 -Platform PlayMode -ResultsDirectory TestResults/G31ArtMap002
.\Scripts\validate.ps1 -LogPath TestResults/G31ArtMap002/validation.log
```
