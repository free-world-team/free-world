## 3. 关键决定

- Atlas 顺序固定为四种 Frame、四种 Panel 和八种 Icon；颜色以外再用轮廓、角标、中心结构和图形语义
  区分，16 格在灰阶下仍唯一。
- 只有 `frame.danger` 可使用精确 P0 危险红 `#E45D45`；其余 15 格检测值为 0，危险状态同时保留三角
  警示角，避免只靠颜色传意。
- 4096 source 只作生产输入；2048 final 直接满足 Runtime Texture 上限，每格 512×512。Frame/Panel
  使用 64 px 九宫格 Border，Icon 保持零 Border。
- Unity 6 已废弃 `TextureImporter.spritesheet`，且它不能可靠覆盖已有 Sprite Editor 数据。本批按 ADR
  0027 使用 Unity 官方 Sprite Data Provider，并按语义名称复用 Sprite ID；两次导入后 `.meta` Hash
  均为 `7E2B481819805845D8DAB69D23BD34DA2DF10442DB6AA3159E5771C6BFDFD38E`。
- 该依赖仅存在于 `Game.Editor`，不进入 Player 或模拟层；Content Schema、存档、Tick、稳定 ID 和运行时
  Addressables 架构均不变。
