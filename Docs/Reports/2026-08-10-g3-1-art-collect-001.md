## 3. 关键架构决定

- 依据 imagegen 技能流程，每个不同候选使用一次独立文字生成，不上传图片参考；批准源统一经洋红键色
  透明化，再由仓库脚本确定性生成 Illustration/Icon 两级 Runtime 输出。
- 文件只使用 `old-court-01`—`06` 稳定身份。当前本地化仍为 Placeholder，G3.3 才冻结玩家可见正式名称；
  本批视觉语义来自三个冻结 Topic 与对应 AcquireRule，不擅自写入新叙事事实。
- 源级 QA 拒绝四类风险：十字状锁芯、类似 Braille 的点阵刻度、类似字形的杯身痕迹、类似吉祥结的
  装饰结及悬叶数量歧义。失败源保留在 provenance，但不处理、不导入。
- `old-court-06` 的三片悬叶必须分离，产生 14.06%–14.75% 覆盖率；其专属下限设为 13%，其余五件
  保持 18%。所有 final 仍保留固定安全边，未通过放大、粘连或改变三片数量规避门禁。
- 测试分别计算 1024 Illustration 与 256 Icon 的 RGBA 和 luminance＋Alpha Hash，两组均 6/6 唯一。
- 只有十二个 `final/` 文件可寻址；批准/失败 source、working、Prompt 和 provenance 均不可寻址。
- 未改变长期架构、Schema、存档或包依赖，无需新增 ADR。

## 4. 实际执行的命令

```text
Codex built-in ImageGen（六份批准源＋四份失败候选；每次独立文字调用、无图片输入）
Copy-Item（十份项目绑定生成目录文件复制到仓库 source/rejected；保留原件）
python remove_chroma_key.py --auto-key border --soft-matte --transparent-threshold 12 --opaque-threshold 220 --despill（六次）
python Scripts/process-qinglan-collectibles.py（首轮在 old-court-06 coverage=0.1403 处停止）
python Scripts/process-qinglan-collectibles.py（增加有证据的 old-court-06 专属 13% 下限后完成）
python remove_chroma_key.py --force（六次）＋ collectible processor（第二次批准轮）
Unity -executeMethod Game.Editor.QinglanVisualAssetImportCommand.Run（十二个 final 各一次，Start-Process -Wait）
.\Scripts\test.ps1 -Platform EditMode -ResultsDirectory TestResults/G31ArtCollect001（361/362，provenance Hash 手工转录少一位）
Get-FileHash＋ConvertFrom-Json（全部 source/output Hash 映射复核）
.\Scripts\test.ps1 -Platform EditMode -ResultsDirectory TestResults/G31ArtCollect001（修正后）
.\Scripts\test.ps1 -Platform PlayMode -ResultsDirectory TestResults/G31ArtCollect001
.\Scripts\validate.ps1 -LogPath TestResults/G31ArtCollect001/validation.log
```

第二次后处理后，6 份透明 working、6 份 source master、6 份 Illustration 和 6 份 Icon 共 24/24
SHA-256 字节一致。
