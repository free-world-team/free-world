## 1. 执行结论

当前 Demo 的玩法闭环、2.5D 空间、正式资源加载和 60 秒自动门禁均已成立，但“功能存在”与“美术成品感”
之间仍有明显差距。现阶段最缺的不是继续增加资源数量，而是把已有内容纳入同一套构图、层级、材质、动效
和反馈语言。

本次实际抓取的五个 1920×1080 战斗帧显示：

- 写实柔光页面背景、偏厚涂角色、粗描边矢量技能图标、程序化纯色 HUD 同屏出现，缺少统一的形状语法、
  光照方向、边缘处理和纹理频率；
- HUD 在屏幕四角和底部形成四块大面积深色矩形，血/盾/经验条过宽，任务列表和常驻危险图例长期占据
  战斗空间；
- 地面由大块完整贴图硬切拼接，五区边界呈竖直断层，砖缝尺度、颜色和道具透视不连续；
- 45—60 秒时同款翠绿拾取物、同类敌人和红色危险圈大量重叠，玩家、敌人、拾取物、伤害数字与技能
  反馈竞争同一视觉频段；
- 危险圈只有弱透明描边，预警、命中、持续危险与可拾取物的优先级没有形成稳定的亮度、形状和节奏梯度；
- 当前页面基本复用“左侧标题 + 纵向卡片列表”，能完成流程，但没有角色选择、地图选择、构筑选择和结算
  各自应有的信息架构与情绪节奏；
- 1080p HUD 存在 11—17 px 正文/图标等级等小字；已有字号缩放，但默认值和高密度背景下的可读性不足。

因此建议把下一阶段定义为 G4.2“视觉品质重制”，先做一个 90 秒垂直样板，而不是直接重画全部资源。
推荐主方向为“青瓷剑境”：低饱和手绘战场、青玉与米白界面、墨青轮廓、克制金色进度、高纯度危险色，
以锐利剑气和风痕作为唯一高亮动势。核心角色、敌人、Boss、UI 框架和标志性 VFX 坚持第一方重制；
开放许可素材只补充通用控件、基础纹理、粒子源图和临时声音，经二次风格化后方可进入候选。

## 3. 根因分析与优先级

| 优先级 | 根因 | 当前表现 | 影响 | 处理原则 |
|---|---|---|---|---|
| P0 | 缺统一视觉圣经 | 每类资源像独立作品 | 第一眼像素材拼装 | 先冻结风格 Token 和禁用项 |
| P0 | 战斗语义无层级 | 拾取、技能、危险、伤害数字同频竞争 | 高密度时看不清自己和威胁 | 建立敌我/危险/VFX 四级预算 |
| P0 | UI 信息架构复用过度 | 多页面只是换背景的纵向列表 | 页面缺少身份和决策重点 | 各页面按任务重新布局 |
| P0 | 地图拼块显露 | 区域硬切、平铺重复、透视不连贯 | 世界像贴图测试场 | 统一 texel、接缝、Decal 和遮挡 |
| P1 | 动作与反馈节奏薄弱 | 帧变更很多但重量、停顿、残影无层次 | 攻击“发生了”但不爽 | 以预备—动作—回收节奏重做 |
| P1 | HUD 占屏与小字并存 | 大块面板 + 11—17 px 信息 | 既挡画面又难读 | 缩容、渐进披露、提高默认字号 |
| P1 | 颜色直接写在代码 | 同语义颜色散落于 UI/Presentation | 难以全局调色与做主题 | 表现层 Token 化，保持模拟不变 |
| P2 | 页面过渡与音画联动不足 | 切页和按钮反馈以瞬时显隐为主 | 缺少精致感与节奏 | 建立 80—500 ms 动效梯度 |

这些基准共同说明的不是“特效越多越先进”，而是画面必须有稳定的视觉优先级：玩家与致命危险优先，
伤害确认其次，构筑成长再次，环境和装饰主动让位。这是本方案的推断和设计原则，不是对竞品实现的事实声明。

## 5. 推荐视觉方向：“青瓷剑境”

### 5.1 方向选择

| 方向 | 说明 | 优点 | 代价 | 决定 |
|---|---|---|---|---|
| 青瓷剑境 | 哑光手绘、青瓷釉裂、宣纸雾、锐利剑气 | 延续现有青岚品牌，最少推翻世界观 | 需统一重制 UI/VFX/地面 | **推荐** |
| 纸本机关 | 木版、纸偶、折页式 UI | 识别度强，制作可控 | 与现有柔光场景和角色冲突大 | 不选 |
| 低模仙庭 | 3D 低多边形、体积光和材质 | 空间层次强 | 需重做角色/地图/管线，扩大范围 | 不选 |

### 5.2 视觉支柱

1. **清**：环境不抢主角，背景中低对比，局部雾化；同时屏幕中只允许一个最高亮度事件。
2. **锐**：剑、风、闪避、暴击使用细而快的方向笔触，不用通用圆形发光代替动作。
3. **润**：UI 和安全/成长反馈使用青瓷釉面与米白纸感；高光窄，面板大面积保持哑光。
4. **险**：敌对信息只用朱砂/赭橙，高危必须再叠加形状、方向、边界动画和声音，不能只靠颜色。
5. **旧庭复苏**：五区从灰、冷、静逐渐恢复青、金、动，完成目标应留下持久且可见的环境变化。

### 5.3 颜色与材质 Token

所有颜色先进入表现层 Theme/Token 资源，再由 UI、材质、VFX 和辅助模式引用；不得继续在新组件中散落
魔法数。此改动不触及 Simulation。

| 语义 | 建议值 | 使用范围 |
|---|---|---|
| `Ink-950` | `#102A2D` | 主面板、暗描边、HUD 背板 |
| `Ink-800` | `#1C4243` | 次级面板、非战斗信息 |
| `Jade-500` | `#42B8AD` | 玩家、交互、焦点、剑气中亮 |
| `Jade-200` | `#A9E5D8` | 高光、选中描边、友方边缘 |
| `Rice-100` | `#F2EBD8` | 主文字、纸面、剑刃 |
| `Gold-400` | `#D7B55A` | 稀有度、成长、可确认操作 |
| `Cinnabar-500` | `#E4573D` | 一般敌对预警 |
| `Cinnabar-300` | `#FF8B62` | 即将命中的高危边缘 |
| `Void-700` | `#563C76` | 异常/诅咒；不得承担普通危险 |

限制：普通环境饱和度上限约 35%；普通技能不使用纯白满屏闪；青色只表达玩家/友方；红橙只表达伤害
和敌对；金色只表达成长/稀有/确认；同一语义必须同时提供形状或运动通道。

材质统一为三族：宣纸/石面（粗糙低反射）、青瓷/玉（小面积柔亮边）、剑气/危险（短时发光）。
现有厚重黑外发光和多层霓虹描边不进入新资产。

### 5.4 形状、边框与字体

- 面板：4/8 px 基础栅格，8—12 px 圆角只用于现代操作层；叙事/地图用切角与不对称窄边；
- 边框：常态 1—2 px，选中 2—3 px；不再用 10 px 以上多重边框包围每张卡；
- 图标：24/32/48/64 px 四档，统一 2 px 视觉笔重；技能主图允许面绘，系统操作只用线性图标；
- 字体：继续使用已登记 Noto Sans/Serif CJK SC；正文 Sans，叙事/大标题 Serif；不新增书法字体风险；
- 1080p 默认 PC 正文不低于 18 px，战斗关键数值 20—24 px，页面标题 40—56 px；11—15 px 仅可用于
  非关键装饰且必须能随 150%/200% 缩放；
- 标准正文/关键控件目标对比度 ≥4.5:1，大字和大图形 ≥3:1，高对比模式目标 ≥7:1。该指标对齐
  [Xbox Accessibility Guideline 101](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/101)
  与 [XAG 102](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/102)。

### 5.5 动效 Token

| 级别 | 时长 | 场景 | 规则 |
|---|---:|---|---|
| Micro | 80—120 ms | Hover、Pressed、焦点移动 | 不弹跳整屏；位移 2—4 px |
| Short | 160—220 ms | 卡片选中、Toast、HUD 数值变化 | 透明 + 轻位移，避免纯缩放 |
| Medium | 280—360 ms | 页面进出、升级冻结、Boss 名牌 | 可用遮罩/笔触揭示 |
| Hero | 450—700 ms | Boss 入场、显化、结算主结果 | 低频使用，可被“减少动态”关闭 |

所有动效必须支持 Reduce Motion；闪烁、震屏、伤害数字密度和拖尾长度继续服从现有设置，并补充实时预览。

## 6. UI/UX 完整重构规格

### 6.1 全局壳层

- 1920×1080 采用 64 px 外安全边界，16:9 主基准；1280×720、2560×1440、3840×2160、21:9 必须
  逐页截图验收；
- 页面从“通用左栏列表”改为：背景情绪层、页面身份层、主要决策层、帮助/系统层四层；
- 同一时间只允许一个主要 CTA；返回、详情、筛选作为次级操作；
- 键鼠 Hover、键盘/手柄 Focus、Pressed、Selected、Disabled、Locked、New、Error 都有独立视觉；
- 状态不能只靠变色：Selected 加形状/位移，Locked 加锁与原因，Disabled 加文字，New 加角标和一次性动效。

### 6.2 页面逐项方案

| 页面 | 当前问题 | 新结构 | 验收重点 |
|---|---|---|---|
| 标题/Profile | 背景承载主要气氛，菜单像覆盖文本 | 左下窄菜单 + 右侧庭院主景；版本/Profile 弱化；主 CTA 金色 | 3 秒内识别“开始”、设置、退出 |
| 角色选择 | 纵向卡片无法比较角色身份 | 中央 3/4 身角色 + 左右选择 + 右侧能力摘要/难度 | 名称、武器、特性、锁定原因一屏读完 |
| 地图选择 | 与角色选择视觉相同 | 五区卷轴/庭院俯视缩略图 + 目标/风险/奖励标签 | 当前区、锁区、目标差异无需读长文 |
| Loadout | 信息堆在卡片段落 | 装备槽、构筑预览、可替换项、确认区四块 | 键鼠/手柄都能预测替换结果 |
| 升级/奖励 | 纵向滚动，战斗背景干扰 | 三卡横排；图标 96 px；名称/标签/核心数值/变化对比 | 5 秒内完成选择，无小字溢出 |
| 暂停/设置 | 选项密度和解释混在一起 | 左侧分类、中央设置、右侧实时预览/说明 | 150%/200%、Reduce Motion、高对比实时生效 |
| 结算 | 结果与叙事同一模板 | 主结果、构筑回顾、关键统计、解锁、下一步分屏 | 胜负、收益、解锁在 3 秒内可见 |
| Hub | 仍像背景 + 菜单 | 可交互庭院热点 + 底部快捷导航 + 右侧目标 | 据点升级有空间变化和“已完成”反馈 |

### 6.3 战斗 HUD

1. 左上生命区缩至最大 360×96：生命为主、护盾叠层、经验改为屏幕底部 6—10 px 细条或环形等级反馈；
2. 顶中只保留计时、波次和 Boss 阶段；调试速度值不得进入正式 HUD；
3. 右上任务默认显示当前主目标 + 最多两个次目标，完整列表按键展开；完成项 600 ms 收束后折叠；
4. 左下构筑栏只显示 6 个核心技能，其他被动折叠到可呼出构筑面板；冷却用径向遮罩，等级不使用 11 px 文本；
5. 常驻危险图例移入教程与可访问性设置，战斗中只在首次遇到新危险时短暂出现；
6. 屏幕中心 45%×45% 设为战斗净区，常驻 HUD 不得进入；
7. 所有 HUD 背板支持 65%—100% 不透明度，高对比模式改为实色，不在复杂地图上直接放白字。

## 7. 世界、美术与动画优化

### 7.1 地图

- 统一地面 texel density、透视和光向；现有 2048×512 大地块不再直接整块铺满屏幕；
- 每区至少提供 Base 4、Edge/Corner 8、Crack/Decal 8、Transition 8 个可组合件；
- 区域边界使用 1.5—3 m 的渐变过渡带、破损压边、苔痕/落叶和局部遮挡，消除直线硬切；
- 地表保持低频，中频只用于路线与地标，高频细节不铺满；玩家附近 4 m 降低纹理对比 10%—20%；
- 五区以材质/植被/建筑语言区分，而不是单纯换底色；完成目标后加入风、灯、叶、泉等持久动态；
- 道具建立 Small/Medium/Landmark 三档轮廓和间距，避免同款凳、鼎、石座机械排队。

### 7.2 角色与敌人

- 锁定统一的头身比、脚底锚点、光从左上、轮廓粗细和投影椭圆；
- 玩家始终保留青玉/米白双层轮廓；敌人只保留一层暗描边，精英增加形状化词缀冠饰而非全身变色；
- 玩家建议保留 4 向，但每向补 Idle 6、Move 8、Attack 6—8、Hit 2—3、Death 8—10 帧；普通敌人优先补
  Attack/Hit/Death，不用方向帧数量冒充动作完整度；
- 远处或被群体遮挡时，玩家轮廓和脚底标识通过深度/遮挡规则增强，不允许被拾取物和友方 VFX 淹没；
- 同屏同类敌人做 2—3 个受控色相/尺寸/配件变体，但碰撞、模拟和 ContentId 不变。

### 7.3 相机与后处理

- 保留正交倾斜和模拟映射；默认构图略向移动方向前置 6%—10%；
- 震屏分轻 1—2 px、中 3—5 px、Boss 6—9 px，强震只作用 120—220 ms，支持强度与关闭；
- 使用一套轻量 URP 颜色分级：压环境高光、保留米白、不把青色推成霓虹；
- Bloom 只服务剑气尖峰和 Boss 核心，不覆盖普通拾取物；暗角只用于 Boss/濒死等短时状态；
- 任何新 Shader/Post Processing 都必须先有性能预算；替换渲染后端或新增第三方包须走 Change Request/ADR。

## 8. 战斗 VFX 与反馈语言

### 8.1 四级视觉预算

| 级别 | 内容 | 同时高亮上限 | 目标 |
|---|---|---:|---|
| V0 | 玩家位置、致命 Telegraph、Boss 核心 | 1 主 + 3 危险 | 永远先看见 |
| V1 | 玩家主武器、命中确认、闪避 | 6 | 表达动作方向和命中 |
| V2 | 常规投射物、状态、拾取吸附 | 24 | 支持构筑，不争主焦点 |
| V3 | 环境尘、落叶、微光、远处装饰 | 动态降级 | 只提供气氛 |

当 V0 出现时，V2/V3 自动降低发光、粒子数和不透明度；当同类拾取物超过 32 个，远处合并为群簇表现，
吸附时再展开。逻辑实体和奖励值不变。

### 8.2 Telegraph 规范

- 预备：危险区使用 20%—35% 填充 + 清晰边界；
- 临界：最后 25% 时间边界由朱砂变亮至橙白，节奏从 2 Hz 增至 5 Hz，但不使用全屏闪；
- 命中：边界向内收束 + 40—80 ms 核心闪 + 120—220 ms 衰减；
- 持续危险：使用稳定纹理流动，不重复播放“即将命中”的脉冲；
- 方向危险使用楔形/箭头，范围危险使用圆/环，直线危险使用双边界，追踪危险使用断续尾迹；
- 色觉模式必须保留上述形状与时间信息。该原则与
  [XAG 103](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/103) 的多感官/非纯颜色通道一致。

### 8.3 命中、伤害数字与掉落

- 轻/中/重击使用三种尺度，不为每次伤害都播放相同白闪；暴击才使用金白尖峰；
- 同一目标 120 ms 内的数字合批；小额连续伤害汇总，暴击/Boss/致命伤保留独立显示；
- 数字具有 1 px 暗边 + 半透明底影，默认不与玩家身体重叠；
- 同类掉落物超过密度阈值后缩小、降低饱和度并群簇；进入吸附半径才提升亮度；
- 状态图标固定在敌人脚底/头顶槽位，不与危险圈共用紫色圆环。

### 8.4 音画与触觉

- UI：Hover、Move Focus、Confirm、Back、Locked、Error 六个短音，音高和响度层级固定；
- 战斗：起手/挥动/命中/材质/击杀分层，普通命中不叠满所有层；
- Boss：预警、阶段、破防、击杀有独立 Stinger；音乐侧链闪避 UI 与关键预警 2—4 dB；
- 同类短音设置并发上限和 50—120 ms 去重窗；
- 新外部音频只允许明确 CC0 或经法律批准的许可，必须保存原始页面、作者、许可、Hash 与修改链。
